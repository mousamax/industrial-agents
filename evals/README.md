# evals/

- Cases live **next to each agent**: `src/app/<agents|flows>/<name>/evals.yaml`.
- `baselines/<name>.json`: the committed reference run. `ia eval <name>` prints a diff against it.
  When you improve an agent: `ia eval <name> --save-baseline` and commit the file in the same PR.
- `reports/`: every local run (gitignored). Logfire keeps the shared history under "Evals".
- `schema.json`: generated by `ia eval-schema` for editor autocomplete in evals.yaml.
